# Howell Navigator

The PDFs of Mortimer Sloper Howell's _A Grammar of the Classical Arabic Language_" are on the Internet Archive: https://archive.org/details/howellarabicgrammar2013/

However, they are cumbersome to browse through. This project uses Quarto to make their contents navigable. It uses The Combined TOC and links from Asim Iqbal's site: https://revivearabic.blogspot.com/2016/03/grammar-classical-arabic-language-howell-arabicgrammar-pdf.html

The output is published at <https://adamiturabi.github.io/howell-navigator>.
